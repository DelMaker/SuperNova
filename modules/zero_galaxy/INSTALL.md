# Нулевая галактика 0.6.0: установка

Модуль готов для тестовой установки администрацией. Он не изменяет файлы ядра; совместимость с другими сборками SuperNova и сочетаниями модулей нужно проверить на копии игры.

## Проверенная среда

- SuperNova 46d0, штатный обработчик флотов и шаблоны OpenGame.
- PHP 7.4.33, 64 bit; `mysqli`, JSON и функции `mbstring` либо их совместимые реализации в ядре.
- MariaDB 10.11.19, InnoDB. Другие версии БД и PHP 8 не проверены. Миграции используют синтаксис MariaDB.
- Современный браузер с JavaScript и BigInt для выбора атакующего флота.

Должны работать обычные полёты и подписанные служебные HTTP-запросы обработчика флотов. В штатной схеме связь `fleets.fleet_end_planet_id` с планетой должна иметь `ON DELETE SET NULL`. Пользователю БД нужны права чтения и изменения игровых записей, создания и обновления таблиц модуля. Серверный `secretword` должен содержать не менее 16 символов; в пакет чужой ключ не входит.

«Капитаны» необязательны. Для отправки капитана и начисления опыта нужен уже установленный совместимый модуль `unit_captain`. Его исходники в архив не включены.

## Состав и баланс

Каталог `modules/zero_galaxy/` содержит код, изображения, переводы, штатные обёртки интерфейса, проверки и настройки:

- `defaults.php` — полный текущий настроенный баланс: семь категорий, стоимости, технологии, фазы, ресурсы, частоты и лимиты. Значения сохранены без сброса.
- `config.php.example` — пример частичных переопределений. Для своих изменений скопируйте его в `config.php` в том же каталоге.
- `SETTINGS.md` — комментарии к параметрам.

Если `config.php` отсутствует, используются значения `defaults.php`. Не копируйте сюда основной конфиг игры, пароли БД или настройки Docker. При обновлении существующей установки сохраните её собственный `config.php` отдельно.

Баланс рассчитан под обсуждавшиеся крупные значения очков. Его пригодность для экономики другого сервера проверяется отдельно. Новые настройки действуют на следующие появления; уже созданные разломы сохраняют исходный профиль и сроки.

`acs_enabled => true` включает совместные атаки на разломы и задан по умолчанию. Для отключения укажите `acs_enabled => false` в `$zero_galaxy_config`: исчезнут кнопки создания и приглашения САБа для атак на разломы и приглашения в выборе цели; сервер также запретит создание и присоединение. Уже летящие САБы при прибытии вернутся без боя. Обычные галактики сохраняют штатное поведение. Используйте PHP `true` / `false` без кавычек; после изменения достаточно нового запроса, либо перезапуска PHP при OPcache без проверки файлов.

В САБе каждый игрок имеет обычный лимит разлома; несколько его флотов в одной группе делят этот допуск. Допустимы до пяти игроков и пяти флотов. Присоединение не продлевает общее время прибытия. При превышении допуска на прибытии возвращаются флоты этого игрока, остальные проводят общий бой; отсутствие цели возвращает всю группу.

В `docs/` находятся описание механик для администрации, анонс и правила для игроков, а также исходный файл лицензии SuperNova. В корне пакета — версия исходников и контрольные суммы файлов. Дампов БД, игроков, локальных секретов, Docker и копии «Капитанов» нет.

## Установка на копию игры

1. Сохраните резервную копию БД и существующего модуля, если он уже установлен.
2. Из распакованного пакета перенесите только каталог `modules/zero_galaxy/` в одноимённое место игры. Имя каталога менять нельзя. Документация не заменяет файлы движка.
3. При необходимости подготовьте `config.php` до первого входа. Чтобы сначала проверить совместимость без новых NPC, задайте `$zero_galaxy_config = ['target_active_per_system' => 0];` в PHP-файле. Это временный режим проверки; рабочий ориентир — `2`.
4. Войдите в игру. Штатный загрузчик подключит модуль автоматически: отдельной регистрации нет. Первый авторизованный запрос создаст три таблицы с префиксом игры: `zero_galaxy_state`, `zero_galaxy_rifts`, `zero_galaxy_npcs`. При включённой генерации начнётся появление разломов.
5. Откройте «Нулевая галактика» либо введите галактику `0` в обычном обзоре Вселенной. При агрессивном кэшировании обновите OPcache, шаблоны и браузер штатным способом своего сервера.

Перед доступом игроков проверьте появление и закрытие планет, шпионаж, атаку из отчёта, выбор флота с лимитом, бой и возврат. Для САБов проверьте приглашение и присоединение, суммарный лимит нескольких флотов одного игрока, единый бой, возврат превышающего участника и скрытие кнопок после отключения конфига. Для обломков проверьте сбор до закрытия, возврат опоздавшего флота без сбора и сохранность уже собранного груза. Обычные галактики должны продолжать работать.

## Проверки и ограничения версии

Версия 0.6.0 прошла в локальном Docker 4759 PHP-проверок и JavaScript-проверки подсказок. Через игровой интерфейс проверены разведка, атака с капитаном, полный рейс переработчиков, совместный бой двух игроков с возвратом флотов и отключение САБов с перезапуском сервера. Проверки находятся в `tests/`; это не подтверждение совместимости с любым сервером и не нагрузочный тест.

- Луны, специальные награды и личные бонусы к боевому лимиту отключены намеренно; САБы управляются `acs_enabled`.
- Повторная отправка того же корректного запроса может создать ещё один рейс: одноразовая защита от повторов пока не реализована.
- При дробных курсах ресурсов клиентская оценка стоимости флота может отличаться от серверной из-за округления. Решение принимает серверная проверка.
- Пользовательские темы, другие обработчики флотов и модули захвата требуют проверки совместимости. Массовые одновременные рейсы не проходили нагрузочное тестирование.

## Обновление и отключение

Не заменяйте обработчик флотов и не удаляйте модуль, пока остаются рейсы в Нулевую галактику или обратно. Отказ в новых отправках при конфликте обработчиков не защищает автоматически уже летящие флоты.

Для остановки задайте `target_active_per_system => 0`, дождитесь исчезновения разломов и завершения всех направленных и возвращающихся рейсов. Только после этого отключайте или заменяйте код, сохранив резервную копию. Автоматического удаления NPC, таблиц и настроек модуля из игры нет.

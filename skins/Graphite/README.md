# Graphite

## Рамки таблиц и праздничная подмена

Рамки используют штатный `border-image` шаблона OpenGame. В обычном режиме
Graphite задаёт симметричную ширину `1em`, одинаковую нарезку и растяжение краёв
без повторения. Селекторы сохраняют штатную специфичность, поэтому CSS ивента
может заменить геометрию и рисунок рамки.

- Большая: `images/border.svg`, 88 × 88, нарезка 11 / 11 / 11 / 11.
- Малая: `images/border_small.svg`, 88 × 88, нарезка 11 / 11 / 11 / 11.

Порядок значений нарезки: верх / право / низ / лево.

Центр изображений прозрачный. Поперечный профиль каждой стороны постоянен:
на стыках с углами нет обрывающихся линий или продольных градиентов. Цветные
акценты находятся только в углах. Для нового рисунка нужно сохранять размеры
срезов и расположение углов. SVG используется для точной геометрии и резкости;
праздничные PNG работают через тот же механизм CSS.

Когда пользователь включает «Отключить рамки-картинки у таблиц», движок добавляет
к `body` класс `no_border_image`. В этом режиме Graphite рисует тонкие плоские
границы. При снятой галочке используются декоративные рамки.

Для совместимости с ивентами:

- Не добавлять `!important` к свойствам декоративных рамок Graphite.
- Не задавать им `border`, `border-image` или фиксированный `border-width`
  в более специфичных правилах навбара, диалогов и отдельных таблиц: эти свойства
  сбрасывают или блокируют штатное оформление ивента.
- Сохранять исходные селекторы OpenGame и исключения `markup`, `noborder`,
  `no_border_image`. Оформление внутренних ячеек и кнопок задаётся отдельно.
- Использовать абсолютные URL `/skins/Graphite/images/...`: движок объединяет CSS
  в `design/cache`, поэтому относительные пути изменят смысл.
- Синхронно обновлять `skin.css` и `skin.min.css`. Движок предпочитает `.min.css`.

Минификация из корня проекта:

```sh
npx --yes --package clean-css-cli cleancss -O0 \
  -o skins/Graphite/skin.min.css skins/Graphite/skin.css
```

Проверка совместимости должна покрывать четыре состояния: обычное оформление,
отключённые рамки, CSS ивента и отключённые рамки при подключённом CSS ивента.
Проверяются обычные таблицы, контейнер вкладок, рыночные услуги, явные большие
и малые рамки, левое меню, навбар и диалог; служебные таблицы остаются без рамок.
Ширина измеряется с учётом шрифта элемента: штатные значения заданы в `em`.

При подготовке проверены все четыре состояния на локальном стенде с оригинальным
PNG Хэллоуина и его CSS-селекторами, включая `!important`. Праздничный модуль PHP
в локальной сборке отсутствует; проверялась его CSS-подмена. Сама тема также
проверена на рабочей странице локальной игры.
